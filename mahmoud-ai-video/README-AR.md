# MAHMOUD AI — منصة إنشاء الفيديو الخاصة

منصة خاصة لإنشاء فيديوهات طويلة وShorts. المستودع عام، لكن ذلك لا يعني أن الموقع منشور؛ لا يوجد نشر تلقائي.

## الموجود في الكود حاليًا
- واجهة عربية/إنجليزية وتسجيل دخول Supabase.
- إنشاء مشاريع خاصة بكل مستخدم مع سياسات RLS.
- توليد سيناريو عبر مزود متوافق مع OpenAI Chat Completions.
- API لتوليد صور المشاهد وحفظها في Supabase Storage الخاص.
- API لتوليد تعليق صوتي MP3 لكل مشهد وحفظه في التخزين الخاص.
- API لإصدار روابط مؤقتة موقعة لملفات المشروع.
- مسارات API تتحقق من جلسة المستخدم وملكية المشروع عبر RLS.

## ما لم يكتمل بعد
- توصيل أزرار واجهة المستخدم بسير التوليد الكامل ومراجعة الصور والصوت.
- مزود Image-to-Video حقيقي ومحدد؛ لا يوجد تكامل فيديو عامل حاليًا.
- طابور مهام خلفي دائم، عامل رندر FFmpeg، وتجميع MP4 وتنزيله.
- اختبار تكامل فعلي بمفاتيح الخدمات ومشروع Supabase حي.

لذلك لا تعتبر النسخة الحالية مولّد فيديو نهائيًا بضغطة واحدة بعد. نقاط API الخاصة بالصور والصوت جاهزة في الكود لكنها تحتاج إعداد الخدمات والتخزين والاختبار.

## الإعداد
1. استخدم Node.js 20 أو أحدث وثبّت الاعتمادات من مجلد mahmoud-ai-video.
2. انسخ .env.example إلى .env.local.
3. أنشئ مشروع Supabase واضبط NEXT_PUBLIC_SUPABASE_URL وNEXT_PUBLIC_SUPABASE_ANON_KEY.
4. شغّل supabase/schema.sql في SQL Editor.
5. شغّل supabase/media-storage.sql لإنشاء bucket خاص وسياسات ملكية الملفات.
6. أضف مفاتيح الخدمات على الخادم فقط: LLM_API_KEY للسيناريو، IMAGE_PROVIDER_API_KEY للصور، وTTS_API_KEY للصوت. يمكن استخدام OPENAI_API_KEY بدل مفتاح الصور والصوت إذا كان نفس مزود OpenAI مستخدمًا.
7. عطّل التسجيل العام في Supabase Auth، وجهّز حساب المسؤول والدعوات.
8. شغّل npm install ثم npm run dev.

## API endpoints
- POST /api/projects/:id/generate-script — إنشاء السيناريو وحفظه.
- POST /api/projects/:id/generate-images — توليد الصور الناقصة للمشاهد وحفظها في bucket الخاص.
- POST /api/projects/:id/generate-voice مع JSON يحتوي sceneIndex مثل { sceneIndex: 0 } — توليد صوت مشهد واحد.
- POST /api/projects/:id/media-url مع JSON يحتوي path — رابط موقّع صالح لخمس دقائق.

## الخصوصية والتكلفة
- لا تضع أي مفتاح سري في متغير يبدأ بـ NEXT_PUBLIC_ أو في كود المتصفح.
- اجعل bucket باسم private-videos خاصًا، ولا تنشئ روابط عامة.
- توليد الصور والصوت يستهلك رصيدًا لدى المزود؛ أضف حدود استخدام قبل فتحه لمستخدمين آخرين.
- لا ترفع ملفات المستخدمين إلى مستودع GitHub.
- لا يتم نشر الموقع من هذا المستودع تلقائيًا.
