# MAHMOUD AI — منصة إنشاء الفيديو الخاصة

نسخة تأسيسية (MVP) لموقع خاص يحوّل الفكرة إلى فيديو يوتيوب طويل أو Shorts، مع مراجعة السيناريو والصور قبل الرندر.

## ما الذي يعمل في هذه النسخة؟
- واجهة عربية/إنجليزية مع RTL/LTR.
- تسجيل دخول بالبريد وكلمة المرور عبر Supabase.
- لا يوجد رابط تسجيل عام.
- دعوات للمستخدمين من صفحة الإدارة (للمسؤول فقط).
- إنشاء وحفظ مشروعات المستخدم.
- فصل بيانات المشروعات بين المستخدمين باستخدام Row Level Security.
- حالات المشروع لتجهيز سير المراجعة: مسودة السيناريو، مراجعة الصور، جاهز للإنتاج.
- منع فهرسة الموقع عبر محركات البحث.

## ما الذي لم يتم توصيله بعد؟
توليد الصور وتحريك الصور والصوت وتركيب MP4 لم يتم توصيلها بعد. تمت إضافة واجهة API لتوليد السيناريو والمشاهد عبر مزود متوافق مع OpenAI Chat Completions؛ وتحتاج إلى ضبط LLM_API_KEY على الخادم. لا ندّعي أن التوليد يعمل قبل إضافة المفتاح واختباره.

## التشغيل محليًا
1. ثبّت Node.js 20 أو أحدث.
2. أنشئ مشروعًا في Supabase.
3. انسخ `.env.example` إلى `.env.local` وضع:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY` (سري، لا تضعه في متغير يبدأ بـ NEXT_PUBLIC)
4. افتح SQL Editor في Supabase وشغّل `supabase/schema.sql`.
5. أنشئ أول مستخدم مسؤول من لوحة Supabase Auth يدويًا، ثم أضف له دعوة أولية في جدول `invitations` قبل إنشاء الحساب، أو أنشئ حسابه أولًا ثم أضف صفه إلى `profiles` يدويًا:
   ```sql
   insert into public.profiles(id,email,role)
   select id,email,'admin' from auth.users where lower(email)=lower('YOUR_EMAIL')
   on conflict(id) do update set role='admin';
   ```
6. في Supabase Auth عطّل **Allow new users to sign up**. الدعوات الإدارية تستخدم خدمة Supabase Admin.
7. شغّل:
   ```bash
   npm install
   npm run dev
   ```
8. افتح `http://localhost:3000`.

## دعوة مستخدم
بعد تسجيل الدخول بحساب المسؤول، افتح `/admin/invites` وأرسل الدعوة. لا تشارك `SUPABASE_SERVICE_ROLE_KEY` مع أي مستخدم أو تضعه في المتصفح.

## الخصوصية قبل النشر
- استخدم HTTPS.
- اترك Storage bucket باسم `private-videos` خاصًا (غير Public).
- لا تحفظ مفاتيح الخدمات في المتصفح.
- اضبط قائمة Redirect URLs في Supabase على نطاق الموقع فقط.
- أضف حدود استخدام ومراقبة تكلفة قبل إتاحة توليد الفيديو للمستخدمين.
- راجع سياسات Supabase Auth والإيميل قبل تشغيل دعوات الإنتاج.

## هيكل المرحلة التالية
1. خدمة كتابة السيناريو وإرجاع JSON للمشاهد.
2. شاشة مراجعة وتحرير السيناريو واعتماده.
3. توليد صور المشاهد وعرضها للمراجعة/إعادة التوليد.
4. تحريك الصور عبر مزود Image-to-Video.
5. تعليق صوتي عربي/إنجليزي، ترجمة، ثم تركيب MP4 باستخدام FFmpeg.
6. طابور مهام للخلفية وتخزين خاص وروابط تنزيل مؤقتة.
