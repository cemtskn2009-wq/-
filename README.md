# MAHMOUD AI

مشروع أولي لمنصة إنشاء فيديوهات طويلة وYouTube Shorts من فكرة مكتوبة.

## ملفات المشروع
النسخة المصدرية الحالية موجودة داخل الأرشيف:
`mahmoud-ai-video-starter.zip`

فك ضغط الأرشيف للحصول على مجلد `mahmoud-ai/` وملفات Next.js وSupabase.

## الحالة
هذه نسخة Starter وليست منصة إنتاج مكتملة. يلزم إعداد Supabase ومتغيرات البيئة، ثم توصيل خدمات توليد النصوص والصور والصوت والفيديو قبل تشغيل إنشاء الفيديو فعليًا.

راجع `mahmoud-ai/README-AR.md` بعد فك الضغط لخطوات الإعداد.
